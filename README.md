# Artist Rejector

Obra web · simulador de bandeja de entrada para artistas.

Te conectás a la Red, postulás a residencias, becas y open calls… y los **rechazos
llegan solos, constantemente, para siempre**. Podés abrir cada mail y leerlo. El
contador de rechazos solo sube.

Los mensajes se generan de forma procedural (organizaciones, programas y fórmulas
de rechazo ficticias, en español e inglés), así que casi nunca se repiten.

## Estética
- Tipografía **Averia Libre**; HUD técnico en **Share Tech Mono**.
- **Cybercore / Serial Experiments Lain**: azul intenso, efecto de TV vieja
  (scanlines, ruido analógico, corrimiento RGB), barras de UI biseladas.

## Cómo verlo
Es HTML/CSS/JS plano, sin build. Abrí `index.html` con doble clic, o serví la
carpeta con cualquier servidor estático.

## Estructura
- `index.html` · `style.css` · `app.js` — la pieza.
- `Image/` — avatares cuadrados de los remitentes.
- `Sound/` — clips de notificación de mail nuevo.
